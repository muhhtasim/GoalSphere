# GoalSphere Deployment

## Local development
- Frontend: http://localhost:5173
- Backend: http://localhost:4000

## Production hosting
- Frontend: Vercel
- Backend: Render or Railway
- Database: MongoDB Atlas

## Environment setup
Use .env files in local development and keep production secrets in the hosting platform environment variables.
